DESIGN LANGUAGE / 06

结构安静，
细节有呼吸。Quiet structure.
Living details.

低视觉噪声的结构，点缀分散在背景与卡片上的曲线与几何形，而不是集中成一张插画。交互状态通过形态与运动表达，而不是增加新的容器。 A low-noise structure with curves and geometry scattered across backgrounds and cards, not gathered into one illustration. Interaction states are expressed through shape and motion, not by stacking new containers.

BENTO / VISUAL SYSTEM

容器即控件Container-as-Control

相关内容共享同一空间。编辑时只改变必要状态，不在原有结构里再套一层新的 UI。Related content shares one space. Editing changes only the necessary state, never nests a new UI layer inside the existing structure.

01 / CONTEXT

真正就地编辑True In-place Editing

顶部标题、左侧 Tab 双击即可改名：不出现输入框、背景不变、字号前后一致，容器大小随文字自然伸缩。Double-click the title above or a tab: no input box appears, background stays the same, type size is unchanged, the container simply resizes with the text.

02 / EDIT

材质表面Material Surface

点阵 + 细噪点 + 非纯黑白，避免纯数字平面感。Dot grid + fine grain + off-neutral tones avoid a flat digital surface.

03 / SURFACE

形态即状态Motion State

点击图标，汉堡旋转为叉号——移动端导航菜单用的就是同一个组件。Click the icon — the hamburger rotates into a cross. The mobile nav menu above uses this exact component.

04 / MOTION

默认可访问Accessible by Default

键盘焦点、语义标签、响应式断点、reduced-motion，都是设计的一部分。Keyboard focus, semantic markup, breakpoints and reduced motion are part of the design.

PROGRESSIVE / SKELETON LOADING

骨架屏加载Skeleton Loading

内容到达前用结构占位，不用转圈或省略号；加载过程本身也是设计的一部分。Structure stands in while content is on its way — no spinners, no ellipses.

06 / LOADING

按需加载Loaded on Demand

元素接近视口时才建立 DOM / 资源，首屏不为不可见内容付费。DOM and assets are created only as elements approach the viewport.

07 / PERF

稳定布局Stable Layout

为异步内容预留尺寸，避免出现明显的位移跳动。Space is reserved for async content to avoid visible layout shift.
