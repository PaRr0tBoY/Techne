# 09 · 中英双语 + 无障碍

## 规范要点

- 可翻译文案一律 `data-zh` / `data-en` 成对，JS 用 `hidden` 属性切换（从无障碍树移除，而非仅 CSS 隐藏）。
- 用户自定义内容（Tab 名、站点标题）**不**包翻译对。
- 切换语言时同步更新：`lang` 属性、图标按钮的 `aria-label`/`title`（含当前主题/明暗态）、搜索占位符。
- 语义化导航与 ARIA：`aria-expanded`、`aria-current`、`role="menu"`、`role="menuitem"`。
- 图标按钮必须 `aria-label` + `title`（06）。

## 代码

```html
<span data-zh>概览</span><span data-en hidden>Overview</span>
```

```js
const searchInput=document.getElementById("searchInput");
function isEnglish(){return root.lang==="en"}
function applyLang(en){
  root.lang=en?"en":"zh-CN";
  document.querySelectorAll("[data-zh]").forEach(el=>{el.hidden=en});
  document.querySelectorAll("[data-en]").forEach(el=>{el.hidden=!en});
  const label=en?"Switch language":"切换语言 / Switch language";
  langBtn.setAttribute("aria-label",label);
  langBtn.title=label;
  searchInput.placeholder=en?"Search…":"搜索…";
  updateThemeA11y();
  updateModeA11y();
}
```

页面初始化：`applyLang(false)`；`<html lang="zh-CN" data-theme="verdigris" data-mode="dark">`。
