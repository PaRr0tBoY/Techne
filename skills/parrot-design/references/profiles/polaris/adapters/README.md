# Parrot Design 组件库 · v7

把 `design-template-v8.html`（组件全览 demo）拆成独立组件。每个文件 = 规范要点 + 可直接复用的代码（HTML/CSS/JS）。

## 组合规则

1. 每个页面 = **00-base.md（必读）** + 与需求相关的组件文件。
2. **页面结构由用户需求决定**，组件只提供样式语言：导航放顶栏还是侧栏、用不用 hero、卡片怎么排，都按需求来。组件文件里的示例布局（如 2×2 菜单网格）是实例，不是规范。
3. 组件代码可直接复制，但必须按需求调整内容和结构——**禁止整段复制 demo 页的标记**。
4. 所有取值用 `var(--token)`，不得硬编码色值/间距。
5. 交付前自检：与 `design-template-v8.html` 的逐字行重叠率 > 20% → 布局没有按需求重排，重构后再交付。

## 新增/修改组件

组件来自 `design-language-document-v7-DESIGN.md`（不可变发布版）。要改组件：先改 DESIGN.md，再同步组件文件与派生文件，发布新版本。不要把新规范只写进组件文件。
